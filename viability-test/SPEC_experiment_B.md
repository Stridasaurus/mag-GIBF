## S.1 Shared Monte‑Carlo skeleton (all B runs)

Per brief §9 (still valid), with the B6 arms added:

```
for cell in scenario_grid:
    for trial in range(n_trials):
        rng   = Generator(seed derived from (master_seed, cell_id, trial))
        X     = simulate_snapshots(cfg, tm, truth, rng, coherence)   # complex phasors
        S     = build_csm(X); lam, U = eigendecompose(S)
        K     = 2 (oracle: B1/B2/B4/B6b)  |  estimate_n_sources(lam, N, "mdl") (B3 record‑only, B6a solver‑fed)
        V     = eigenmodes(lam, U, K)      # sqrt(lam)-weighted; IDENTICAL to all solvers
        maps  = { l2, gibf, mmv }          # same A, same V, same solver params
        record per-trial metrics(map, truth) per method
    aggregate mean ± 95% CI per method per cell
```

Invariants (roadmap §2 / brief §0.2): `A` real DF‑only (post Gate V), `assert np.isrealobj(A)` in every solver except B4's `phantom_phase` arm; snapshots are complex frequency‑bin phasors; GIBF and MMV receive the identical `V`, `A`, `eps_frac`, `beta`, `weight_floor`, `max_iter`, `tol`, and grid‑reduction setting per run.

**CI convention (pinned here):** percentile bootstrap over trials, 2000 resamples, seeded from the cell id; one method everywhere, named in the memo. "Non‑overlapping 95 % CIs" always means the two per‑method CIs (the conservative ≈ α 0.006 reading in §5‑D2).

### B6 — prior‑misspecification stress cells (the only principled per‑mode regime)

## S.4 Mode‑selection design (consolidated)

`modeselect.estimate_n_sources(eigvals, n_snapshots, criterion="mdl")`, log‑domain Wax–Kailath per brief §6.5 with eigenvalue floor `1e‑18` **in trace‑normalized units** (amended 2026‑07‑27, see below); returns `K̂` plus the full AIC(k)/MDL(k) arrays.

> **Amendment 2026‑07‑27 — the floor is re‑expressed in trace‑normalized units (ROADMAP §8 2026‑07‑27, Strider's §8‑ii sign‑off ruling 2).** The pinned numeral `1e‑18` is **unchanged**; only the units it is denominated in change. Applied to *raw* eigenvalues it is an **absolute** floor calibrated for an O(1) unit‑power scenario (Tier 1's convention), so against Experiment B's real ground CSM (~`1e‑24` T²) every eigenvalue clipped to the same value, the log‑domain LLR flattened to 0 for every candidate `k`, and MDL/AIC reported `K̂ = 1` at 100 % of B3 cells (the 2026‑07‑21 finding). `estimate_n_sources` now trace‑normalizes internally (`λ × 2/trace`, the repo‑wide convention) **before** applying the floor, making it scale‑free by construction. This is content‑preserving: the Wax–Kailath LLR `N·p·(mean log λ_tail − log mean λ_tail)` is provably invariant to `λ → cλ` for `c > 0`, and the penalty terms contain no eigenvalues — so the normalization is a no‑op on any full‑rank spectrum and changes only *which* eigenvalues the floor catches. The floor's sole remaining job is keeping `ln` finite on the exact zeros of a rank‑deficient sample CSM (`n_snap < n_channels`), which is exactly what it was for. **Why in the units and not at the call site:** this was the third mis‑fire of one root cause (Card A Tier 2's gap‑conditioning statistic → §S.6.1's solver scale convention → §S.4), and the same sitting's grid refinement (§S.10) moves the CSM scale again. `tests/test_modeselect.py` pins the invariance across 48 decades including the rank‑deficient case; the 2026‑07‑21 dual raw/normalized reporting path is retired (reproducible at commit `12ff377`). The brief's "AIC or MDL" ambiguity is resolved: **MDL is primary** (§8‑viii); `criterion` stays an argument so B3 can score both. Consumers: B3 (record‑only, both criteria), B6a (solver‑fed, MDL), downstream D3 diagnostics (MDL). `K̂` is clipped to `[1, K_max]` with `K_max = 6` (guards the pathological all‑modes case; clipping events counted and reported).

## S.6 Fairness protocol (PINNED 2026‑07‑19)

> Draft → **pinned before any Experiment‑B code or run exists** (timing ruling: ROADMAP §8, 2026‑07‑19 amendment — pre‑registration must precede confirmatory runs; "at manifesto lock" was written before PR #1 cleared the runway, and §9 itself permits "before"). Each component carries its pin date + rationale. The protocol is built to defeat the two standing reviewer attacks by construction: **"MMV was under‑tuned"** (components 1, 5) and **"that isn't Suzuki's GIBF"** (component 2).

1. **Matched regularization (pinned 2026‑07‑19).** One shared literal config object for both sparse solvers: `eps_frac = 0.01`, `p_norm = 1.0`, `weight_floor = 1e‑10`, `beta = 0.9`, `max_iter = 50`, `tol = 1e‑4`, `min_active_factor = 2`; a pytest asserts both solvers read the identical object. **The μ tie is tie‑by‑rule, not tie‑by‑value:** neither solver carries an explicit `μ` — each realizes its penalty through `eps = eps_frac · λ_max(A W Aᵀ)` (underdetermined branch; `eps_frac · λ_max(AᵀA)` overdetermined) computed on its **own current weighted system** (per mode per IRLS iteration for GIBF; once per iteration on the row‑norm‑weighted system for MMV). What is matched is the rule: it is scale‑covariant, which is what "equally tuned" means across structurally different priors — matching raw ε across solvers would mismatch effective penalty strength. The realized ε is recorded per solve into the §S.5 outputs. The L2 baseline's ridge uses the same rule on the unweighted system.
   **Scale convention (pinned 2026‑07‑19):** every solver receives `V/s` with `s = √λ₁` of the cell's CSM; recovered amplitudes are rescaled by `s` (intensities by `s²`) before metrics. This preserves inter‑mode ratios and makes `weight_floor` and `tol` scale‑free — without it, tesla‑scale amplitudes (`|a| ~ 1e‑12`) would sit below the `1e‑10` floor and the floor would dominate the weights. Precedent: the Tier‑2 trace‑normalization lesson (repo `CLAUDE.md`; §8 2026‑07‑19 gap‑conditioning entry).
2. **Symmetric grid reduction (pinned 2026‑07‑19).** Same `beta = 0.9` and same on/off setting per run. GIBF prunes per mode by `|aᵢ|`, MMV by row norm — that asymmetry is inherent to the methods, so symmetry means *same β, same setting*, not identical retained sets. **Confirmatory cells run reduction ON** (Suzuki's published GIBF includes grid reduction; the "that isn't Suzuki's GIBF" defense requires running his algorithm as published), with an OFF pair at the same `n_trials` reported as descriptive rows. B1 still runs both ways. Pinned consequence: the §8‑ii power‑calc SD inputs (B1 pilot SD and the 50‑trial mini‑pilot SD) are read from **reduction‑ON** rows, and the mini‑pilot runs reduction ON.
3. **L2 baseline (pinned 2026‑07‑19).** Computed at every cell, same `eps_frac` rule on the unweighted system, same scale convention; a context row only — never adjudicated, never tuned.
4. **Single‑source exact‑recovery gate (pinned 2026‑07‑19).** Before any comparison cell counts, **all three solvers** (roadmap §4 item 1 governs over this section's earlier "both sparse solvers" draft — the stricter superset) must localise one isolated DF source, placed at the grid cell nearest the array centroid, to the **exact cell**: global argmax of `I(j)` equals the true cell (τ = 0 — deliberately stricter than §8‑v's `τ_r = 1`). Oracle `K = 1`, `n_snap = 64`, base `eps_frac`, two tiers: **(i)** noise‑free deterministic, single run (roadmap §4's "noise‑free well‑separated" case); **(ii)** 20 dB Monte‑Carlo, 10 trials, all must pass, seeds per the §S.1 scheme. Sparse solvers run both reduction settings; L2 runs tier (i) only. **Any failure halts Experiment B** (solver bug, not science); gate artifacts archived like Gate V's.
5. **Regularization‑sensitivity panel (pinned 2026‑07‑19).** At every confirmatory cell (win cells at both SNRs, both null cells at the same SNR pair, B6a): rerun both sparse solvers at `eps_frac × {0.1, 0.3, 1, 3, 10}` — ×1 **is** the headline run — on the **same trials** (identical seeds give identical `X`/`S`/`V`/`K̂`; the data does not depend on `eps_frac`, so the marginal cost is solver time only), at full confirmatory `n_trials`, paired. Report the signed mean gap + 95 % CI per band point (percentile bootstrap, 2000 resamples, seeded from (cell id, band index)). **Fragility rule (operational, pinned pre‑data):** a cell's verdict is **regularization‑fragile** iff any band point's mean gap is opposite‑signed to the ×1 headline **and** that point's 95 % CI excludes zero — a significant reversal. Loss of significance without reversal is reported as "attenuated at band edge(s)" and is not fragile; both facets are always reported. A fragile cell's confirmatory claim is demoted to descriptive (the win rule then cannot be satisfied through that cell; the loss rule still needs ≥ 1 null; B6 has a single cell). Rationale: the draft's bare "flips sign" had no operational reading against Monte‑Carlo noise.

The station‑sampling anchor is a property of the array, is computable before any experiment, and gives the confirmatory coordinate a physical meaning rather than an accidental one.

## S.12 d=8 also degenerate; d=2 accepted as the confirmatory coordinate (2026‑08‑28)

**d=8's result.** The confirmatory pass at `d=8` (`run_experiment_B2B6_d8.py`, branch `b2b6-confirmatory-d8` / PR #4) came back **more decisively degenerate than `d=3`**: the B1 matched cell and the coherent mini‑pilot both returned gap SD = 0.0000 exactly, 50/50 trials, all three solvers (L2, GIBF, MMV) exact‑recovering — P_sep = 1.00 across the board. ## S.13 Grid‑density / reduction‑threshold interaction, characterized (2026‑08‑28)

**Origin.** An abandoned, never‑merged exploratory branch (`geometry-rescale-sonnet`, 2026‑07‑27, superseded by the actual §S.10 33×17 rebuild) flagged but did not fix a confound: `grid_reduction`'s stopping rule (`len(cols) < min_active_factor × n_channels`, §S.6(1)) is an **absolute** threshold, not one that scales with grid density — so a denser pole grid mechanically needs more IRLS iterations before reduction can trigger. That branch measured 7 iterations at a 17×17 (289‑pole) grid vs 1 at the archived‑brief 11×11 (121‑pole) grid — and explicitly declined to fix it, since doing so would mean touching the pinned §S.6(1) config without authorization. The finding was never carried into this file or `ROADMAP.md`, and the actual shipped grid (33×17, 561 poles, §S.10) is denser still — so the question was open, not resolved, until this section.

**Mechanism, confirmed directly from `solvers.py`.** Column pruning under `grid_reduction` is deterministic: each iteration keeps `floor(β × current_count)`, independent of data. At the current grid (`n_poles=561`, `n_channels=75`, `min_active_factor=2` ⇒ threshold `150`, `β=0.9`), the geometric decay from 561 crosses below 150 at iteration **13**, exactly — a fixed property of the pinned constants, not of the physics or the trial.

**Empirical check (2026‑08‑28, 15 trials, `d=2`, φ=90°, 5dB, coherent, reduction ON — the confirmatory setting):**

| | GIBF (per mode) | MMV |
|---|---|---|
| n_iter | 13 on most trials; 7–8 on a few (own tol check fires first) | **exactly 13 on all 15 trials** |

**Read.** Both solvers are bound by the *same* deterministic 13‑iteration ceiling — it comes from the shared config applied to the same starting grid, not either method's own dynamics, so the confound is symmetric by construction. The one asymmetry observed (GIBF occasionally exits early via its own convergence check; MMV essentially never does in this sample) gives MMV *more* refinement budget on average, not GIBF — the opposite direction from a confound that would inflate this project's hoped‑for GIBF advantage. The 13‑iteration floor is also **independent of `d`** (grid size doesn't vary with source separation), so it does not differentially affect the `d=3`/`d=8`/`d=2` comparison either.

**Disposition:** characterized and documented, not fixed — there is nothing pinned to fix; the absolute‑threshold rule itself remains §S.6(1) as pinned. Reduction‑OFF context rows (§S.6(2)) show real GIBF/MMV divergence (GIBF mean 26.6 iters, MMV mean 33.9, wide per‑trial spread) but those rows are descriptive, never adjudicating, per the same section. **Open, low‑cost follow‑up:** future runner scripts should log `n_iter` into their manifests (neither `run_experiment_B.py` nor the `d=8`/`d=2` confirmatory scripts currently do) so this stays auditable without re‑deriving it by hand each time.

### Off-grid row (A4): specification (fixed 2026-10-11, before any implementation or run)

*Decided by Strider in conversation on 2026-10-10 (cells) and 2026-10-11 (offset form); pairing was a recommendation he accepted. No code existed and no result had been seen. Changes nothing adjudicated.*

**Why this form.** Option B's "half a cell north" was an assistant-proposed value and its direction was never discussed. It is one fixed point and is cross-axis to the east-west pair separation. A per-trial uniform offset answers the question the row exists to answer (how much of the result survives realistic source positions) with no arbitrary direction, and it contains any fixed offset as a sub-case because each trial's offset is recorded.

1. **Cells.** The six B2 d=2 cells (phi = 90, 0, 180 degrees x 5, 10 dB), each with `|rho|` = 0.85, n_snap = 64, oracle K = 2. Not B6a (its solvers are fed K-hat = 6; an off-grid B6a would stack two misspecifications, and its physics is the 5 dB win cell).
2. **Source placement.** The on-grid pair (centre row 16, columns 7 and 9) is translated rigidly by one per-trial offset `(u, v)`, with `u` (north, in rows) and `v` (east, in columns) each drawn uniformly on [-0.5, +0.5). One row is one pole step in latitude (0.5700 degrees) and one column is one pole step in longitude (1.6667 degrees). The two sources share the offset, so the index separation stays d = 2. Per-source independent offsets are not used (they would make the separation vary by trial).
3. **Data.** Fields for the two translated positions are generated per trial by the same DF-only adapter (`transfer.py`), the same stations and the same shell, evaluated at the exact off-grid positions. The coincidence and finiteness guards apply. Inversion uses the ordinary 33 x 17 grid unchanged.
4. **Truth for the metrics.** The fractional positions `(16 + u, 7 + v)` and `(16 + u, 9 + v)` in index units, passed to the unchanged `delta_r_bar` and `p_sep` (tau_r = 1 inclusive; peak rule and 10% threshold; miss penalty) with no change to `metrics.py`.
5. **Randomness and pairing.** Offsets are drawn from their own generator, keyed by the sibling cell id and trial, so no on-grid draw is perturbed. Each off-grid cell reuses the source-phasor and noise draws of its on-grid sibling (same phi, SNR, d = 2), so only the kernel columns differ. Trial t of the off-grid cell is therefore the same random situation as trial t of its sibling, moved by `(u_t, v_t)`.
6. **Arms.** The headline arm only: oracle K = 2, grid reduction ON, eps x1, for L2, GIBF and MMV. No OFF twin, no regularization panel (P10, P12), no no-early-exit arm. Stop reasons and iteration counts are recorded as for every solve. n = 10,000 trials per cell (P14).
7. **Label and adjudication.** `descriptive_offgrid`, its own cell family and role. Never adjudicated; excluded from `adjudicate()`/`adjudicate_from_dir()` and from the d-axis arm by construction.
8. **Pre-specified reporting** (so the dependence on offset is not a forking path):
   - the per-trial offsets, saved;
   - results in three bins of offset magnitude `r = sqrt(u^2 + v^2)`: [0, 0.25), [0.25, 0.5), [0.5, 0.7071], expected about 20%, 59% and 21% of trials;
   - results by axis: `|u|` and `|v|` each in [0, 0.25) and [0.25, 0.5];
   - the paired off-grid-minus-on-grid contrast, with shared bootstrap resample indices, for miss rate, P_sep, Delta r-bar and the signed GIBF-MMV gap;
   - the per-trial outcome transition table (correct / miss / mislocated, on-grid to off-grid) per method.
9. **Tests required with the implementation.**
   - Regression: for every existing cell, the on-grid trials (X, eigendecomposition, K-hat) under a test seed are byte-identical before and after the change.
   - Zero-offset invariant: with `(u, v) = (0, 0)` an off-grid trial reproduces its sibling's data exactly.
   - Offsets lie in range, are recorded, and are independent of the sibling's draws.
   - The adjudication path ignores the family.
10. **Disclosures that go with this row.**
    - It removes grid-position coincidence only. The generating kernel, shell height, white noise, absence of induction and conductance error, and point-source pairs (not distributed FLR fields) are unchanged. The claim is "off-grid source positions", not "no inverse crime".
    - The pair is about 1.4% physically closer at a half-cell north offset (125.2 km to about 123.4 km), because longitude cells shrink with latitude.
    - Best-case Delta r-bar is about 0.5 cell per source at a half-cell offset; a one-column lateral slip counts as success on-grid (distance 1.0) but not at a half-cell north offset (1.118 under tau_r = 1).
    - Because trials are paired, the on-grid and off-grid verdicts are not independent replications of each other.

Smoke runs use seed 1 and never write under `results/`. Output: `results/B_viability/b4_b6b/`.

**B4**

2. **Scenario** (brief §9-B4: "re-run B1's incoherent scenario"). Two equal-power incoherent DF sources on the grid's centre row, symmetric about the centre column; `d` in {1, 2, 3, 5, 8}; SNR in {-5, 0, 5, 10, 20} dB; `n_snap` = 64; oracle K = 2; **GIBF only** (L2 and MMV are not run); the shared fairness configuration unchanged. Grid reduction ON is the headline arm; reduction OFF is a descriptive twin (B1 ran both).
3. **Phantom kernel.** `A_phase = A (.) exp(i Phi)` with `Phi[m, j] = 2 pi r[m, j] / lambda_p`, where `r[m, j]` is the straight-line distance between station m (at the ground radius) and pole j (at the shell radius); the three field components of a station share its phase. The same kernel generates the data and is inverted (data and inversion are consistent; there is no kernel mismatch). A phase common to one pole is a gauge and does not change intensities. The real arm uses `A` unchanged. This is the only place a complex `A` is used; the complex-capable solver lives in its own module and the standard solvers keep asserting a real `A`.
4. **An ambiguity in §S.2/brief §9-B4, and how it is resolved.** The brief defines the ramp as "a wave propagating at light speed ... at `frequency_mhz`", and `frequency_mhz` is 15 mHz. That gives `lambda_p` of about 19,986,000 km, i.e. about 4 x 10^-5 wavelengths across the 761 km station longitude span (a phase span of about 2 x 10^-4 rad): an essentially real kernel. *(Corrected 2026-10-12, before any B4 trial: this section was first committed with "about 19,986 km" and "about 0.04 wavelengths", an arithmetic slip of a factor of 1,000 in the prose. The runner computes the value from `c / f` and was never affected; the design below is unchanged and the corrected figure makes the literal arm closer to the real kernel, not further.)* The brief's stated purpose ("how much of acoustic GIBF's separation power came from phase diversity") and its expectation ("a large gap") need several wavelengths across the array. The two readings conflict and which was meant was never recorded. Rather than choose one, B4 is a **dose-response in wavelengths across the station longitude span**: the literal 15 mHz value (about 4 x 10^-5), then **1, 2 and 5**. Five is the largest value for which the pole spacing (63.5 km) stays under half a wavelength (152 km), so the phantom kernel is not aliased on the pole grid. The literal arm answers "what does realistic ULF propagation phase buy"; the others answer "what would acoustic-like phase diversity buy". The values 1, 2 and 5 are agent-chosen; they are justified by that aliasing limit and by spanning from one to several wavelengths, and they are not tuned to any result.
5. **Expectations, stated before any data** (descriptive; departures are reported, not explained away): (E1) the literal arm is indistinguishable from the real arm within Monte-Carlo error; (E2) P_sep at small `d` is non-decreasing in wavelengths across the aperture; (E3) any gain is concentrated at `d` <= 2, since `d` >= 3 is already at ceiling for the real kernel on the B1 grid.
6. **Trials and pairing.** 10,000 trials per cell (P14). For a given (SNR, `d`, trial) every kernel and both reductions share the same random draws (source phasors and noise), so every contrast is paired.
7. **Reporting.** Per (SNR, `d`, kernel, reduction): delta r-bar and P_sep with 95% percentile-bootstrap CIs (2,000 resamples, indices shared across kernels within a cell), miss rate, stop-reason counts; the paired phantom-minus-real contrast with its CI; `d_min` (smallest `d` with P_sep >= 0.8) per (SNR, kernel, reduction); the P_sep-versus-`d` curves. Label `descriptive_b4`.

**B6b**

8. **Cells** (§S.2-B6b, with the §S.12 coordinate: §S.2's `d` = 3 is superseded by `d` = 2). phi = 90 degrees, |rho| = 0.85, 5 dB, `d` = 2, `n_snap` = 64, oracle K = 2, reduction ON; L2, GIBF and MMV on the same trials; 10,000 trials.
9. **Variants.** `none` (control); `step_away` (source 2 moves one column away from source 1 at snapshot N/2 + 1); `step_toward` (one column toward source 1 at snapshot N/2 + 1); `iid` (source 2's position at each snapshot drawn uniformly over the 3 x 3 neighbourhood of its nominal cell). Source 1 is fixed. §S.2 did not give the direction of the step, so both directions are reported and neither is called primary.

Diagnostics, reported alongside: delta r-bar and P_sep against the displaced end-point cell and against the time-averaged position. Peak rule, 10% threshold, tau_r and miss penalty as everywhere else. Variants share the same draws (source phasors and noise); only source 2's kernel column varies by snapshot. All positions are grid nodes, so no new kernel evaluation is needed.
11. **Expectation, stated before any data:** the jitter degrades MMV more than GIBF, because the shared-support prior is false across the window. Not a rule.

**Common**

12. **Required tests:** the complex solver equals the standard GIBF solver on a real kernel (indices, iteration counts, stop reasons); the standard solvers still reject a complex `A`; the phantom kernel has unchanged magnitudes and tends to `A` as the wavelength grows; the general snapshot simulator equals `simulate_snapshots` for constant columns and consumes the same random stream; the jitter column schedules are as specified; seeds are distinct from every prior seed; guards (committed-and-clean, no overwrite, smoke never under `results/`).
